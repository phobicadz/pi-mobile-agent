## Testing Tips

1. Copy one of the markdown lines above
2. Paste it into the chat input
3. Send the message to Pi
4. Pi may transform or reference the link in its response
5. Click on any rendered link to test if it opens

### Example test prompt:

"Can you tell me about this resource? [Flutter Docs](https://flutter.dev/docs)"

This tests whether:
- Links are properly rendered in markdown
- Links are clickable and styled distinctly
- Links open in the browser/external app
